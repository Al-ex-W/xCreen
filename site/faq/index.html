Is there an open-source Rewind alternative for Mac?

xCreen. It reads your screen with local OCR and has your Hermes Agent write short takeaways into your Obsidian daily notes.

It is Apache-2.0, runs on macOS 14+ and needs Hermes Agent. Retrace (MIT, macOS 13+ on Apple Silicon) is another open-source option for Mac, and screenpipe is source-available under its own commercial license. See the comparison.

What happened to Rewind AI?

It shut down. The Mac app stopped capturing on December 19, 2025, after Meta acquired Limitless, according to 9to5Mac.

The rewind.ai domain now belongs to an unaffiliated site. Former users looking for a replacement can compare xCreen, screenpipe, Retrace, Goldfish and Microsoft Recall on the alternatives page.

Is there an app that remembers what I did on my screen on a Mac?

xCreen does. Ask it things like "What was the error I saw in the build log this morning?"

It reads the foreground window with local Apple Vision OCR and saves a screenshot every 10 active seconds. Ask from the menu-bar tray, the macOS 26+ "Ask xCreen" Spotlight action, or xcreen ask in a terminal. Screenshots stay on your Mac for seven days; short takeaways go into your Obsidian daily notes.

Does xCreen send my screenshots to the cloud?

If your Hermes model is a cloud model, yes. OCR and storage are local, but every 5 active minutes a batch goes to your Hermes provider, and so do your questions.

That provider's retention rules then apply. xCreen has no server of its own and stores no API keys. For on-device inference, configure a local model in Hermes. While the Integrity switch is ON, no new screenshots, OCR or automatic batches happen. Details: SECURITY.md.

Does xCreen work with Obsidian?

Yes. Set a vault and short takeaways go into that day's daily note, plus related notes when they fit.

If nothing is worth keeping, nothing is written. Raw screenshots and OCR stay outside the vault in ~/Library/Application Support/xCreen. A missing dated note may be created with a minimal heading; templates are never executed. Setting the vault to empty (xcreen settings set vault "") disables Daily-note writing.

Which AI models can xCreen use?

Any model configured in Hermes. Pick one in the tray.

The default for the xCreen session is Claude Haiku 5.5 on your Anthropic account (anthropic / claude-haiku-5-5). Changing it with the tray picker or xcreen model default PROVIDER MODEL affects only the xCreen session, never Hermes's global default. An unavailable model is reported rather than silently replaced. Check that your chosen route accepts images.

Is xCreen free?

Yes. It is open source under Apache-2.0, including for commercial use.

Forks that redistribute it must keep the Apache notices; no advertising credit is required. You pay only for whatever model provider you configure in Hermes, if any.

Does xCreen work on Windows or Linux?

No. macOS 14 or later only (Spotlight needs macOS 26).

If you need Windows or Linux, screenpipe lists macOS, Windows and Linux support; Goldfish lists macOS and Windows; Microsoft Recall runs on Windows 11 Copilot+ PCs. See the comparison.

How is xCreen different from screenpipe?

xCreen is a Mac app that feeds your Hermes Agent and writes to Obsidian. screenpipe runs on macOS, Windows and Linux, records audio too, and uses a source-available commercial license.

screenpipe captures via the Accessibility tree with OCR fallback and can use local or cloud AI. xCreen captures foreground-window screenshots with local Vision OCR, does not record audio, and requires Hermes Agent. Choose screenpipe if you need Windows/Linux or audio. Sources are on the alternatives page.

How is xCreen different from Microsoft Recall?

Recall is built into Windows 11 Copilot+ PCs and processes snapshots locally. xCreen is an open source Mac app that uses your Hermes provider for inference.

xCreen also writes takeaways into your Obsidian notes instead of only keeping a searchable timeline.

How long are screenshots kept?

Seven days, then they are deleted.

Anything already sent to your model provider or saved in Hermes history follows their retention rules, and notes in your vault stay until you delete them. Local storage uses private file permissions but is not encrypted, so use FileVault. Deletion does not guarantee forensic erasure.

Can I pause capture?

Yes. Turn Integrity on in the tray, or run xcreen integrity on.

That stops new screenshots, OCR and batches. Integrity is ON (capture off) at first launch and keeps your choice across restarts. Only your own tray or CLI action changes it; the model and screen content cannot turn capture on. Capture also pauses automatically when the Mac is locked or asleep, or when an excluded app is in front.

Does xCreen capture passwords?

It can. Password managers, System Settings and lock screens are skipped, but browser password fields, password-manager extensions and private windows are not.

Anything visible on screen in an eligible app can end up in screenshots, OCR and model batches. Turn Integrity ON before sensitive browsing. The exact exclusion rules are in SECURITY.md.

Do I need Hermes Agent to use xCreen?

Yes. xCreen has no model or API keys of its own and uses your Hermes Agent profile read-only.

If you don't want an agent dependency, Retrace or screenpipe may suit you better.

How do I install xCreen?

Download the zip from release 1.0.0, or build it: git clone https://github.com/Al-ex-W/xCreen.git && cd xCreen && bash scripts/install.sh.

You need macOS 14+ and Hermes Agent; building also needs Xcode/Swift and Python 3. Full steps, including uninstalling: INSTALL.md.
