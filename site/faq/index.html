Is there an open-source Rewind alternative for Mac?

Yes: xCreen is a free, Apache-2.0 screen memory app for macOS 14+ that captures what you see with local OCR and lets your own Hermes Agent write sourced insights into your Obsidian Daily notes.

It needs a working Hermes Agent install and is a developer preview. Retrace (MIT, macOS 13+ on Apple Silicon) is another open-source option for Mac, and screenpipe is source-available under its own commercial license. See the sourced comparison.

What happened to Rewind AI?

Rewind shut down: its Mac app stopped capturing on December 19, 2025, after Meta acquired Limitless, according to 9to5Mac.

The rewind.ai domain now belongs to an unaffiliated site. Former users looking for a replacement can compare xCreen, screenpipe, Retrace, Goldfish and Microsoft Recall on the alternatives page.

Is there an app that remembers what I did on my screen on a Mac?

Yes, that is what screen memory apps such as xCreen do: xCreen reads the foreground window with local Apple Vision OCR, saves a screenshot every 10 active seconds, and lets you ask questions like "What was the error I saw in the build log this morning?".

You can ask from the menu-bar tray, the macOS 26+ "Ask xCreen" Spotlight action, or xcreen ask in a terminal. Raw evidence is kept on your Mac for seven days; useful findings are written into your Obsidian Daily notes with links back to their evidence.

Does xCreen send my screenshots to the cloud?

Only if the model route you chose in Hermes is a cloud provider: OCR and storage are local, but every 5 active minutes a batch of captured evidence goes to whichever provider your Hermes route uses, and so do your questions.

That provider's retention rules then apply. xCreen has no server of its own and stores no API keys. For on-device inference, configure a local model in Hermes. While the Integrity switch is ON, no new screenshots, OCR or automatic batches happen. Details: SECURITY.md.

Does xCreen work with Obsidian?

Yes: when you configure a vault, the model appends useful, source-linked insights to that day's note in your existing Obsidian Daily notes folder.

If nothing in a batch is worth saving, the batch is marked skipped and nothing is written. Raw screenshots and OCR stay outside the vault in ~/Library/Application Support/xCreen. A missing dated note may be created with a minimal heading; templates are never executed. Setting the vault to empty (xcreen settings set vault "") disables Daily-note writing.

Which AI models can xCreen use?

Any model your Hermes Agent setup has configured: xCreen lists Hermes's configured routes and lets you pick one for the xCreen session.

The default for the xCreen session is Claude Haiku 5.5 on your Anthropic account (anthropic / claude-haiku-5-5). Changing it with the tray picker or xcreen model default PROVIDER MODEL affects only the xCreen session, never Hermes's global default. An unavailable model is reported rather than silently replaced. Check that your chosen route accepts images.

Is xCreen free?

Yes: xCreen is free and open source under the Apache-2.0 license, including for commercial use.

Forks that redistribute it must keep the Apache notices; no advertising credit is required. You pay only for whatever model provider you configure in Hermes, if any.

Does xCreen work on Windows or Linux?

No, xCreen is macOS-only (macOS 14 or later; the Spotlight action needs macOS 26).

If you need Windows or Linux, screenpipe lists macOS, Windows and Linux support; Goldfish lists macOS and Windows; Microsoft Recall runs on Windows 11 Copilot+ PCs. See the comparison.

How is xCreen different from screenpipe?

xCreen is a Mac-only, Apache-2.0 app that feeds screen context into your own Hermes Agent and writes sourced insights into Obsidian Daily notes, while screenpipe is a cross-platform (macOS, Windows, Linux) recorder that also transcribes audio, under a source-available commercial license.

screenpipe captures via the Accessibility tree with OCR fallback and can use local or cloud AI. xCreen captures foreground-window screenshots with local Vision OCR, does not record audio, and requires Hermes Agent. Choose screenpipe if you need Windows/Linux or audio. Sources are on the alternatives page.

How is xCreen different from Microsoft Recall?

Microsoft Recall is a built-in Windows 11 feature for Copilot+ PCs that processes snapshots locally, while xCreen is an open-source macOS app whose model inference goes to whichever provider your Hermes Agent uses.

xCreen also writes distilled findings into your Obsidian notes rather than only keeping a searchable timeline.

How long are screenshots kept?

Seven days: raw screenshots and OCR text expire automatically after seven days.

Anything already sent to your model provider or saved in Hermes history follows their retention rules, and insights written into your Daily notes stay until you delete them. Local storage uses private file permissions but is not encrypted, so use FileVault. Deletion does not guarantee forensic erasure.

Can I pause capture?

Yes: the Integrity switch in the tray, or xcreen integrity on, stops all new screenshots, OCR and automatic batches.

Integrity is ON (capture off) at first launch and keeps your choice across restarts. Only your own tray or CLI action changes it; the model and screen content cannot turn capture on. Capture also pauses automatically when the Mac is locked or asleep, or when an excluded app is in front.

Does xCreen capture passwords?

It can: known password-manager apps, System Settings and lock/login screens are excluded, but browser password fields, password-manager browser extensions and private/incognito windows are not detected or redacted.

Anything visible on screen in an eligible app can end up in screenshots, OCR and model batches. Turn Integrity ON before sensitive browsing. The exact exclusion rules are in SECURITY.md.

Do I need Hermes Agent to use xCreen?

Yes, a working Hermes Agent install is required: xCreen does not include a model or keep API keys and uses your Hermes profile read-only.

If you don't want an agent dependency, Retrace or screenpipe may suit you better.

How do I install xCreen?

Clone the repository and run the installer: git clone https://github.com/Al-ex-W/xCreen.git && cd xCreen && bash scripts/install.sh.

You need macOS 14+, Xcode/Swift, Python 3 and Hermes Agent. The build is not notarized; use a stable signing identity so macOS keeps the Screen Recording permission. A prebuilt ad-hoc signed zip is on release v0.1.0. Full steps, including uninstalling: INSTALL.md.
