xCreen: open-source screen memory for macOS

xCreen is a free, open-source (Apache-2.0) screen memory app for macOS. It reads what is on your screen with local OCR, keeps the raw evidence on your Mac for seven days, and has your own Hermes Agent write useful, source-linked insights into your Obsidian Daily notes.

It is an open-source alternative to Rewind, Retrace, screenpipe, Goldfish and Microsoft Recall for people who already run Hermes Agent on a Mac. You can ask it what you saw from the menu bar, Spotlight or the terminal.

Developer preview (v0.1.0). Not notarized and not security-audited. Capture is off by default.

What it does

  • Ask about what you've seen. From the menu-bar tray, the macOS 26+ "Ask xCreen" Spotlight action (it fills the question in, you submit), or xcreen ask in a terminal.
  • Local capture with dedup. Apple Vision OCR runs on the foreground window at most once per second, and text that is at least 90% similar to the last snapshot is dropped. A screenshot is saved every 10 active seconds.
  • One Hermes session, not a new chat each time. Every 5 active minutes (or 30 images), a batch goes to a single persistent xCreen session in your Hermes Agent.
  • Sourced insights in your Daily notes. The model appends only useful findings to that day's note in your Obsidian vault, each linked to its captured evidence. If nothing is worth saving, the batch is marked skipped.
  • Integrity switch. One switch, controlled only by you, stops all new screenshots and OCR. It is ON at first launch and keeps your choice across restarts.
  • Any model you configure. Pick any model your Hermes setup has configured. The xCreen session default is Claude Haiku 5.5 via OpenRouter.

How it works

  1. While Integrity is OFF and every safety gate passes (Mac unlocked and awake, permission granted, foreground app not excluded), xCreen samples the foreground window for local OCR.
  2. Near-duplicate OCR is discarded; screenshots are saved every ten active seconds to private files under ~/Library/Application Support/xCreen, outside your vault.
  3. Five active minutes (or 30 images) form a durable batch, sent to the same dedicated xCreen session in Hermes Agent.
  4. The bundled runtime gives that session only scoped tools: OCR search and listing, image lookup, and a writer that appends source-bound insights to capture-date Daily notes.
  5. Each batch completes only after an explicit saved or skipped result and verified receipts, so a crash does not cause blind resends or duplicate notes.

Privacy and safety

  • What's captured: screenshots and OCR text of the eligible foreground window, only while Integrity is OFF and the Mac is unlocked and awake.
  • Where it's stored: private local files outside your vault. This storage is not encrypted, so use FileVault. Only distilled, source-linked insights go into Daily notes.
  • Retention: raw evidence expires after 7 days. Anything already sent to your model provider or saved in Hermes history follows their retention rules. Deletion does not guarantee forensic erasure.
  • Excluded: known password managers (1Password, Bitwarden, LastPass, Dashlane, KeePass, Apple Passwords, Keychain), System Settings, lock and login screens, and xCreen itself.
  • Not protected: browser password fields, password-manager browser extensions and popovers, and incognito/private windows are not detected or redacted. Turn Integrity ON before sensitive browsing.
  • Integrity is user-only: the model and screen content cannot turn capture on. Screen text is treated as untrusted evidence, never as instructions.

Full rules and limits: SECURITY.md.

Requirements

  • A working Hermes Agent install is required. xCreen does not include a model or keep API keys. It uses your Hermes profile read-only.
  • Local OCR does not mean local inference. Batches and questions go to the provider behind your chosen Hermes route, and that provider's retention rules apply. For on-device inference, configure a local model in Hermes.
  • Developer build. Built from source with Swift/Xcode, not notarized. Use a stable signing identity so macOS keeps the Screen Recording permission across reinstalls.
  • macOS 14 or later, Xcode/Swift and Python 3. The Spotlight action needs macOS 26 or later.

Install

git clone https://github.com/Al-ex-W/xCreen.git && cd xCreen
bash scripts/install.sh           # builds, installs to ~/Applications, copies `xcreen` to ~/.local/bin
xcreen status                     # Integrity should report ON (capture paused)

Turn Integrity OFF from the tray when you want capture to start. The install guide covers vault setup, signing, verification and uninstalling. A prebuilt, ad-hoc signed zip is attached to release v0.1.0; macOS Gatekeeper blocks it until you allow it in System Settings → Privacy & Security.
